No benchmark fits, predictions or scores were run by this preparation.

An entire 32-tree forest counts as one estimator attempt; disclose that
convention. Keep current-source aliases rather than refitting identical arms:
passing B aliases A; signed/binary A aliases the new source-matched median HGB.
Never reuse older source-dependent outputs as controls. Retain all twelve
categories, including 18 blocked PPR target/year/method slots among 216 slots.

Reuse `LeafCDFModel.fit`, `MedianBoostingModel.fit`,
`RoleCountBoostingModel.fit`, their existing forecast/evaluator functions and
the frozen reference implementation. The old campaign CLIs hardcode other
sources, context panels or Week 6; the original CDF runner scores each trial
after reading labels. A small separately registered orchestrator must instead
freeze all query, model, alias and forecast bytes before one scoring phase.
This is not permission to change the learners or search their hyperparameters.

Take modeled and primary roles from the pinned category dictionary. Preserve
its unused context declaration for schema validation even though only base is
fit. Report primary-role and all-offered populations, sparse/unknown rows,
fallbacks and unrun/failed slots. All preprocessing and priors use earlier
training only. CDF numeric lower medians face MAE; its means face MSE separately.
Anytime TD faces Brier and log loss. Only actual distributions receive proper
distribution scores; do not invent a numeric HGB law. Pool rows before losses,
retain annual cells, and use prespecified game/week-dependent uncertainty.

The existing model serializers include training-binding frames; CDF artifacts
also contain empirical outcomes and leaf assignments. These artifacts must
remain private. Serialize through the existing quota and freeze manifests.
CDF scoring recomputes forest assignments/laws without refitting, which still
needs inference/time accounting.

Before execution, register exact input/code/environment identities, unused
candidate budget, wall/CPU/RSS and per-fit ceilings, shared storage headroom,
row/scoring incidence limits, reporting reserve and all decision rules. The
168/66 figures are ceilings, not a runtime guarantee or a completed search.
Do not silently override the canonical compute budget.

Omit Week 6 from this minimal benchmark. Its original cutoff predates these
source receipts. Any later extension needs a separately declared retrospective
reconstruction and cannot inherit operational as-of or prospective eligibility.
The independent audit's broader role/allocation, FTN charting, NGBoost,
distribution-sensitive forests and stacking proposals remain separate, untested
experiments.
