# Archived exact execution wrappers

These seven files are byte-for-byte copies of the wrappers actually frozen for
the original benchmark, failed first-score recovery and completed report-only
v2 consumer. They are archived execution evidence, not another active pipeline
or scheduler. The core learners, source/evaluator modules and policies are
linked in the parent report.

They expect their original private namespace, corresponding immutable execution
freeze, exact code checkout/interpreter/dependencies, inputs and consumption
markers. Copying them into this public directory does not supply those private
artifacts or authorize another invocation of a consumed experiment. Restored
replay must preserve original evidence and use a separately declared output and
resource budget. Do not run a failed or consumed wrapper again to replace its
receipt. The original and first recovery remain FAILED.

The publication contains no raw source bodies, feature/forecast/outcome rows or
fitted weights. Hashes and public code alone cannot reproduce unavailable
private NFL data. The wrappers document the actual process guards and reporting
derivative; software verification does not add NFL observations.
