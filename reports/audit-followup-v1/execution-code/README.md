# Archived terms-probe execution

These are byte-identical copies of the reviewed supervisor and actual execution
freeze used for the one completed terms-only invocation. They document that
execution; **do not run them as a new acquisition**. The sole invocation and
output are already consumed, and no retry was registered.

The freeze contains code/config/dependency/timeout-binary bindings and private
namespace paths, not source bodies, football records, credentials or model
weights. The complete body and immutable request/response/quota receipts remain
private. Source publication time and acquisition rights are not inferred from
the successful HTTP response. The aggregate receipt records the result and
independent integrity review.
