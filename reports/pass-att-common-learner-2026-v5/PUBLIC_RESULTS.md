## Fixed procedure and controlled additions

All arms used the same38 cached player-history features, training-only FixedDesign preprocessing/missing indicators,32 ExtraTrees,depth8,minleaf30,seed1701 and fixed95% empirical-leaf/5% support-prior law. Only training policy changed in H1–H4:

1. H1 trains on eligible current-season labels weekly; below60 supported training rows it uses the authenticated older CDF reference. Its cached feature definitions still include earlier-season history, so it is not a pure current-season information system.
2. H2 trains weekly on eligible previous-plus-current-season labels.
3. H3 trains weekly on multiseason eligible labels using the fixed365-day half-life by label availability. The same weights enter splits, leaf masses and priors; no half-life search occurred.
4. H4 fits historical relationships once before the evaluated season and consumes the current cutoff-qualified38-feature state.
5. The sole role ablation adds depth rank, starter flag, group size, source age and missingness to H4 with the same training rows and learner. It was not chosen after seeing a history-policy winner.

H1 had266 fallback opportunities,112 with supported outcomes; each other CDF procedure had30 fallback opportunities,one scored. System metrics include those fallbacks. The fully trained H1 diagnostic has99 matched supported rows; it is reported separately and does not replace the full population.
