# Completed missing modern CDF controls

Seven retained annual CDF packages produced fourteen distinct count products without fitting or estimating new priors. All new mean and lower-median vectors were privately frozen and read back before their outcome labels were decoded. The original blocked members and strict API check remain unchanged. These are new retained-law reconstructions, rather than recovered original vectors.

2025 covers 272 regular-season games and 18 weeks; 2026 covers the 93 supported games in Weeks 1–6. Both periods are exposed historical development evidence with the original assumed seven-day source timing. Historical website/raw/R0 forecasts are unavailable for these panels. The already completed 2026 passing-attempt reconstruction is reused by the wider program and was not rerun.

Independent postexecution row arithmetic and public privacy review passed. Managed private terminal retention and fresh-process owned readback passed. Restoration from a different host remains unverified. No candidate was selected or deployed by this wave.

## Remaining scope

- Modern annual ResponseCDF, count CatBoost and declared HGB median packages remain absent from this retained catalog; no new fits were scheduled. Completions now have CDF results but still need those relevant modern challengers.
- Exact website PPR remains blocked by complete scoring labels. The Week 7 comparisons are a separate execution owner and population.
- The original source timing remains an assumption about revised historical data. Authentic publication clocks, role changes, injuries and teammate availability were not repaired or tested by this wave.
- No distribution calibration, probability-above-line, market/+EV, website-relative gain, scientific qualification or production activation follows from these results.

The first external timing wrapper failed before timeout/Python/model startup because `/usr/bin/time` was unavailable. Its exit-127 failure was preserved. The authorized Bash timing continuation executed one actual NFL main: seven model loads, seven exact original fixture replays, 43,801 query row incidences and one scoring phase. It used 54.014 CPU seconds / 57.177 wall seconds and retained 1,967,553 managed artifact body bytes. Zero fits, new priors or HTTP calls occurred.
