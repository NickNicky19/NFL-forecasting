# Finite dynamic opportunity backend

Code preparation only. No actual NFL study, import, fit, forecast, scoring,
network request or managed storage write has been executed for this backend.
The source-owner six new consumer methods have a separate, uninvoked software
packet. The integrator owns its exact registration, review, freeze and GO.

## Single execution route

`tools/freeze_dynamic_opportunity_v1.py` prepares metadata; the integrator and
independent reviewer seal it. The only eventual invocation is the existing
GNU timeout,600seconds, calling `tools/dynamic_opportunity_study_supervisor.py`
with `--freeze` and `--freeze-sha256`. Its one worker is
`tools/run_dynamic_opportunity_study.py`. There is no invocation in this doc.

The supervisor authenticates the timeout executable/parent/argv, arms the worker
parent-death guard before imports, and checks explicit known PIDs/start ticks,
CPU and RSS. Its accepted READY/GO barrier requires positive authenticated RSS
before science imports. A missing live RSS counter fails; only exact owned
Popen termination plus actual post-reap CPU/high-water accounting can reconcile
the known exit race. Every resource sample is checked. The last32 samples,
peaks, counts and exact failure/termination snapshots are retained; this is not
a claim to retain a complete high-frequency timeline. Per-package native-call
markers use the existing reviewed20second protocol, bounded to54 attempts.

Budgets: one600wall/600CPU/1GiB/2numerical-thread study,54 packages,
600,000 row incidences,16 prior-vector formations,48MiB new content under the
unchanged512MiB global quota; no retries, fits, model unpickles or HTTP.
The worker and supervisor set Arrow CPU/I/O pools to2. Query/control projections
and source predicates remain distinct from scoring-role outcome reads.

## Chronology and source population

The unchanged source producer and `AnnualInputs` helper own calendar, physical
source identities, index/cache and requests. Both tasks advance together in
original chronological order; all six settings reuse one request per offer.
Annual priors use only earlier seasons available strictly before the earliest
original annual cutoff, including supported January prior-season REG games.
Eight elapsed same-team/season slots include DNP, missing and unknown states.
The original strict kickoff+7day source rule remains. This can force many
fallbacks after seven-day turnarounds. It is not repaired by inferred roster
continuity or backdated availability.

All2020 forecasts freeze before2021 priors; both development years freeze before
common-cohort six-setting MSE selection. All2022–2024 packages freeze before
final outcomes or comparator errors. This is exposed historical reconstruction,
not prospective issuance or fresh confirmation. Development has no archived CDF;
invalid/missing requests abstain and remain in coverage. Future annual canonical
failures retain the exact original CDF count mean or signed-yard median.
Auxiliary target-count failures abstain. No historical raw Sleeper or SITE is
invented. All-position carry/target-credit sums remain incomplete recorded
proxies, never certified NFL totals or a finite joint allocation.

## Factored private artifacts

One context per year; one source-qualified request per year/task with lossless
interned tables; earlier-only priors;54 compact forecast files; one final label
table per year/target; and authenticated scored/loss views preserve every original
offered row, fallback and missing value. Source/raw files are referenced, not
copied or published. Development2020/21 row references bind their newly persisted
annual context and explicit parent-filter view, not false unfiltered ordinals.

`restore_request_view(manifest,records,tables)` consumes authenticated DataFrames
and restores the exact source-owner request codec. `score_factored_view` consumes
authenticated context/forecast/label frames and calls the unchanged point scorer.
Changed points carry no inherited CDF law fields or invented probabilities.
Exact file selectors and original evaluator hashes reconstruct each paired-loss
view; repeated large pair tables are not copied into the cache.

The preflight reserves the original4MiB reporting/failure allowance separately
from6MiB execution inventory/bootstrap and5MiB once/year projected contexts.
Its planning estimate cannot waive the exact prewrite unique-CAS/global quota.
Yearly nested request copies are released from memory only after immutable
persistence/year freeze; no retained file or failed trial is deleted.

## Decisions and all twelve targets

Canonical rush attempts, receptions and receiving yards receive separate direct
comparisons against the five source-matched controls and matched static model.
Auxiliary targets use an explicitly named count contract and simple controls.
Whole-policy scores include every fallback; informed-only matched diagnostics
remain descriptive. The new nomination requires at least2% primary gain against
both CDF and matched static, equal finite coverage, at most2% absolute bias/p95
regression and at most5% annual primary regression. The old helper's CDF/role_B
nomination is separately retained, never substituted. Every nomination still
requires later independent confirmation and is neither scientific qualification
nor release readiness. Other canonical targets retain references; exact PPR
remains unqualified. No gain transfers to combined yards, fantasy or TDs.

The website, scheduler, frozen RB/H3/receptions studies and public defaults are
unchanged. Actual runtime/backend model settings are unattested.
